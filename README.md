# Vórtex Sub

Vórtex Sub, de Vortex Company: edita y sincroniza subtítulos SRT y VTT sobre la previsualización del video, con ajuste global de tiempos, renumerado y exportación limpia. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
